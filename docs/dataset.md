# Dataset

To aquire the structures for the initial dataset structures were retrieved based on different characteristics.
- search for `nife hydrogenase` -> (548 structures 06.03.26)

Deduplicate with `python -m src.db.deduplicate_raw_structures dat/raw_structures`

## Description
- `benchmarking_subsets` -> randomized split into subsets for benchmarking
- `dedup_dimer` -> raw structures transformed into dataset with only dimers and deduplicated by rcsb id
- `raw_structures` -> structures downloaded from rcsb.org
- `single_chains` -> single chains, generated by creation of database from raw_structures
